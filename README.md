# Jame Assistant

Jame Assistant is a voice assistant with a graphical interface built using Kivy.

🔹 Features
- Uses speech recognition to understand voice commands in Ukrainian.  
- Provides speech output with pyttsx3.  
- Supports basic commands:  
  - Search on Wikipedia  
  - Open Spotify, YouTube, Firefox, PyCharm  
  - Tell jokes via pyjokes  
- Greets the user depending on the time of day.  

🔹 Kivy Interface
- Window size: 550×450 pixels with a dark gray background.  
- Main label: “Welcome to Jame Assistant!”  
- Button: “Press me!” to start the assistant.  
- Command list displayed as a text block.  

🔹 Workflow
- When the button is pressed, the assistant starts listening for commands.  
- Executes actions based on recognized keywords.  
- Ends when the user says “Goodbye” or “bye”.  

---

This project combines a voice assistant with a GUI, allowing interaction both by voice and through the application interface.
